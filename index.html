Soy un joven de 21 años motivado, con un gran deseo de superación y experiencia en desarrollo Backend con Java Spring, móvil con Kotlin y Jetpack Compose además de web con Angular, React, Node.js y TypeScript.

Últimos Proyectos

Gestor de Tickets

Actualmente, estoy desarrollando un gestor de tickets de incidencias usando Spring Boot con arquitectura de microservicios y un frontend en Angular. Cada servicio tiene su propia base de datos MySQL levantada con Docker, e incluye autenticación con Keycloack, comunicación entre servicios con Kafka, y registro de servicios con Eureka Server y un API Gateway para centralizar las peticiones. El objetivo del proyecto ha sido practicar una arquitectura realista y escalable, parecida a la que se usa en entornos profesionales.

Comprit-It

Comprit-It es una aplicación móvil para Android desarrollada con Jetpack Compose, diseñada para facilitar la creación de listas de la compra de forma rápida y organizada. Permite al usuario crear categorías personalizadas de productos, añadir productos directamente desde la vista de creación, registrar supermercados y obtener indicaciones mediante Google Maps. También ofrece un historial de compras filtrable por mes, trimestre o por un rango personalizado. Además, incluye una visualización de los gastos mensuales mediante gráficos, y la opción de exportar o restaurar la información en formato Excel o en uno compatible con la aplicación.
